# БЛОК 09 — применение Refero / Resend

Референс: https://styles.refero.design/style/0d914ef0-fa84-4c60-a9aa-cef0b5eb6e5d

Это адаптация визуальных принципов под вымышленный барбершоп, а не копия продукта Resend. Дополнительные плагины, MCP-подключения, Tailwind и сборщик для страницы не требуются.

## Подключение

`dist/index.html` подключает локальные шрифты, затем `tokens.css`, затем `style.css`. Файл `tokens.css` содержит общие параметры темы. Компоненты используют эти переменные, поэтому тему можно корректировать в одном месте.

Основные параметры:

| Роль | Значение |
| --- | --- |
| Фон | `#000000` |
| Заголовки | `#ffffff` |
| Основной текст | `#f0f0f0` |
| Вторичный текст | `#a1a4a5` |
| Границы | `#292d30`, 1 px |
| Небольшой акцент | `#c84949`, читаемый текст `#e69a9a` |
| Кнопки и поля | радиус 6 px |
| Фотографии, карточки и окна | радиус 16 px |
| Ширина контента | до 1200 px |
| Интервал разделов | 96 px на большом экране, 64 px на мобильном |

Кнопки прозрачные с контуром. Нет цветных заливок, теней, неоновых свечений и светлых секций. Фиолетовый используется для небольших деталей и состояния выбранного времени.

## Типографика

- Inter: интерфейс, основной текст, заголовки разделов.
- Playfair Display: только крупный заголовок первого экрана, открытая альтернатива коммерческому Domaine из референса.
- JetBrains Mono: небольшие подписи, стоимость, время, открытая альтернатива Commit Mono.

Файлы шрифтов хранятся в `dist/assets/refero-*.ttf`; определение — `refero-fonts.css`. Во время просмотра сайт не обращается к Google Fonts или Refero.

## Адаптация и сохранённое поведение

Сохранены бренд БЛОК 09, фотографии, услуги, цены демонстрации, фильтры, просмотр фото и демозапись. Яркая бегущая строка заменена полезными кнопками услуг. Нет маленьких пронумерованных подписей над разделами, ранее удалённых пользователем. Нет телефонов, адресов или профилей реальных барбершопов.

Анимация: короткое появление заголовка, постепенное появление секций, небольшое движение фотографии и плавная реакция кнопок. Системная настройка сокращения анимации отключает движение.

## Обновление темы

По запросу пользователя во всех основных разделах применён мягкий красный радиальный фон `#aa2020` с непрозрачностью 42%. Размеры текста увеличены по общей шкале; на телефоне описания услуг имеют размер 18 px.
