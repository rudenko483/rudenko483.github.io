Проекты предназначены для портфолио. БЛОК 09 и СРЕЗ — вымышленные бренды, не связанные с действующими барбершопами. Демонстрационные формы не создают реальные бронирования, заказы и платежи. Цены и изображения иллюстративные.

GitHub Pages публикует ветку `main`, каталог `/`. БЛОК 09, СРЕЗ Студия, VANTA и «Тихий сад» содержат готовые HTML, CSS, JavaScript и изображения. Основной сайт «СРЕЗ» живёт в отдельном репозитории.

Для передачи заказчику отправьте ссылку нужного сайта. Чтобы передать право редактирования одного проекта, перенесите его в отдельный репозиторий заказчика, а затем проверьте публикацию и обновите ссылки в метаданных. В этом репозитории несколько проектов и общие файлы `portfolio-kit/`. Для статического проекта скопируйте и папку проекта, и `portfolio-kit/`, сохраняя структуру ссылок.

Для запуска реального бизнеса замените демоотзывы, фото команды и пример города фактическими материалами, подключите запись или заказы и проверьте политику конфиденциальности. Для включения Google Analytics укажите свой GA4 ID в атрибуте `data-analytics-id` в HTML соответствующего проекта или в файле `kontur-analytics.js` для KONTUR. Тег загружается после согласия посетителя.
